# @webship.co/workspace-penpot

Penpot, the open-source design and prototyping platform, for the [Webship Workspace](https://github.com/webship/workspace)
dashboard: a builder that makes a real self-hosted Penpot in containers, its tool, the default accounts, the Penpot
step pack wired into the workspace's testing setup, and its AI items.

The builder, the tools, the tests and CI come with the first release, `1.0.0`.
